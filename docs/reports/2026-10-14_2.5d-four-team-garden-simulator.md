# Change Report: 2.5D Four-Team Garden Engine Integration in Tree Simulator (Phase 11.4)

- **Date:** 2026-10-14
- **Scope:** Major Change (2.5D Volumetric Canvas Engine, Game Modes, Simulator Overhaul)
- **Author/Agent:** Antigravity AI
- **Status:** Verified

## 1. Context & Rationale
- **Objective:** Integrate the high-detail, ultra-lightweight 2.5D `FourTeamGardenEngine` into the Tree Arena simulator sandbox (`/tree/simulator`), replacing the heavy Three.js 3D WebGL viewport with a native HTML5 2D canvas running at a rock-solid 60 FPS with 0 KB external library overhead.
- **Root Cause / Motivation:**
  - The previous 3D WebGL engine carried significant client bundle weight, complex shader/lighting dependencies, and camera controls that added cognitive load.
  - The newly provided `FourTeamGardenEngine` renders 4 distinct botanical species simultaneously in isometric 2.5D ceramic pots with organic root flares, volumetric layered foliage pads, blossoms, glowing fruits, seed sprouting metamorphosis, and dynamic fluid physics (dew, nutrients, sun, rain).
  - Directly supports the two core classroom gameplay modes: "Thu thập ý kiến" (Brainstorming) and "Trắc nghiệm 2x/3x" (Quiz mode).

## 2. Technical Implementation Details
- **`FourTeamGardenEngine.ts` (`web/src/lib/`):**
  - Fully typed TypeScript implementation of the 2.5D multi-team garden engine.
  - Configures 4 distinct species archetypes:
    - Nhóm 1: Tùng Ngọc Lục (`bonsai` - Tán mây Bonsai dẹt ngang, `#10b981`)
    - Nhóm 2: Anh Đào Sakura (`sakura` - Tán vòm tròn mềm mại, `#f43f5e`)
    - Nhóm 3: Cam Mặt Trời (`citrus` - Tán xum xuê nhiều tầng, `#f59e0b`)
    - Nhóm 4: Linh Mộc Tinh Vân (`mystic` - Tán vươn cao pha lê, `#8b5cf6`)
  - Isometric ceramic pots with team color bands, root flares, and victory golden auras.
  - Multi-layered volumetric foliage pads with ambient occlusion, midtone, and rim highlights.
  - Fluid drop physics: falling drops (`dew`, `nutrient`, `sun`, `rain`), soil ripples, branch bounce, and leaf shake.
  - API methods: `updateOpinionMode`, `updateQuizMode`, `setTeamGrowth`, `triggerWinner`, `resetAll`, and `spawnDrop`.
- **`FourTeamGardenCanvas.tsx` (`web/src/components/tree/`):**
  - Client-side React wrapper mounting `#garden-canvas` and lifecycle management (`engine.destroy()`).
- **`simulator/page.tsx` (`web/src/app/tree/simulator/`):**
  - Overhauled with mode switching:
    - 📝 **Trắc nghiệm 2x/3x**: Multiplier selection (2x/3x), fast-answer trigger (`<5s` with golden sun drop), wrong-answer trigger (gray rain drop shaking leaves), and combo streak counters.
    - 💡 **Thu thập ý kiến**: Word count target evaluation, standard submission (`nutrient` drop), and excellence submission (`sun` drop).
    - 🎛️ **Chỉnh tay Sliders**: Direct growth scrubbing from 0.06 to 1.0, plus manual drop testing.
  - Preserves SSR-safe dynamic loading (`dynamic(() => ..., { ssr: false })`), contract handlers (`handleSliderChange`, `handleAddDew`, `handleSnapshot`), and snapshot export (`captureCanvasSnapshot`).
- **E2E Suite (`tests/e2e_flow_verification.mjs`):**
  - Added Step 47f assertions verifying `FourTeamGardenEngine` and `FourTeamGardenCanvas` contracts.
